# Windows 11 Single-Folder SHA-256 Hash Checker (Portable)

**Free, 100% offline, zero-install Windows 10/11 PowerShell utility** to generate an Excel-ready UTF-8 SHA-256 hash manifest (`folder_hashes.csv`) for any folder in one double-click - read-only and no coding required.

- **Verified Release ZIP (Gumroad `$0+`):** https://smitht365.gumroad.com/l/olkmxs
- **GitHub Releases:** https://github.com/smitht365247-web/windows11-sha256-hash-checker/releases

## Quick Start
1. Download the latest verified ZIP from [GitHub Releases](https://github.com/smitht365247-web/windows11-sha256-hash-checker/releases) or [Gumroad](https://smitht365.gumroad.com/l/olkmxs).
2. Right-click the `.zip` -> **Properties** -> check **Unblock** -> **Apply / OK**, then extract.
3. Double-click `RUN_CHECKER.bat` and drop or paste any folder path.

## Windows SmartScreen Unblock Note
Because `.bat` and `.ps1` scripts downloaded from the internet are unsigned, Windows SmartScreen may show *"Windows protected your PC"* on first run:
- **Option A:** Click **More info** -> **Run anyway**.
- **Option B:** Right-click the `.zip` before extracting -> **Properties** -> check **Unblock** -> **Apply / OK** -> extract.
